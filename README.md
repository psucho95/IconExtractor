# Icon Exporter

Показывает список установленных приложений с галочками и выгружает выбранные
(имя пакета, activity ярлыка, название, иконки) в ZIP-архив в папке «Загрузки».

## Выгрузка только новых приложений
Приложение запоминает, что уже выгружалось. Всё, что появилось после прошлой
выгрузки, помечено значком **НОВОЕ** и выбрано автоматически.
- **Новые / Все / Снять** — быстрый выбор (Все и Снять действуют на текущий фильтр)
- **Показывать только новые** и поиск — фильтр списка
- **Сбросить историю** — забыть прошлые выгрузки
- Частичный архив называется `app_icons_<дата>_part.zip`

## Сборка APK без компьютера с Android Studio (GitHub Actions)
1. Создай новый репозиторий на github.com и загрузи туда содержимое этой папки
   (вместе со скрытой папкой `.github`).
2. Открой вкладку **Actions** → сборка запустится сама (или нажми **Run workflow**).
3. Через 2–4 минуты внизу страницы сборки появится артефакт **IconExporter-apk** —
   скачай, распакуй, установи `app-debug.apk`.

## Сборка в Android Studio
File → Open → папка проекта → Build → Build APK(s).

## Что в архиве
- `apps.json`, `apps.csv` — пакет, activity, название, версия, системное ли
- `icons/` — оригинальные иконки 192×192
- `icons_current_theme/` — иконки в текущей теме (только если отличаются)
- `adaptive/` — слои adaptive-иконок 432×432

# Router Tool (модуль `routertool`)

Приложение для диагностики роутера Xiaomi AX6000 по SSH — то же, что меню
`router.ps1` на ПК: статус WAN, журнал физического линка, счётчики ошибок порта,
системный лог и лог PPPoE (логин/пароль маскируются), наблюдение за линком в
реальном времени, установка монитора линка, настройки PPPoE, переподключение,
перезагрузка, сохранение всех логов в файл в «Загрузках».

- Скрипты, которые выполняются на роутере, лежат в `routertool/src/main/res/raw/`.
- SSH — библиотека [mwiede/jsch](https://github.com/mwiede/jsch), со включёнными
  старыми алгоритмами (ssh-rsa) для Dropbear на роутере.
- Сборка — тот же workflow, артефакт **RouterTool-apk**.
