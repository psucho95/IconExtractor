# Icon Exporter

Одной кнопкой собирает имя пакета, activity ярлыка, название и иконку каждого
установленного приложения в ZIP-архив в папке «Загрузки».

## Сборка APK без компьютера с Android Studio (GitHub Actions)
1. Создай новый репозиторий на github.com и загрузи туда содержимое этой папки
   (вместе со скрытой папкой `.github`).
2. Открой вкладку **Actions** → сборка запустится сама (или нажми **Run workflow**).
3. Через 2–4 минуты внизу страницы сборки появится артефакт **IconExporter-apk** —
   скачай, распакуй, установи `app-debug.apk`.

## Сборка в Android Studio
File → Open → папка проекта → Build → Build APK(s).

## Что в архиве
- `apps.json`, `apps.csv` — пакет, activity, название, версия, системное ли
- `icons/` — оригинальные иконки 192×192
- `icons_current_theme/` — иконки в текущей теме (только если отличаются)
- `adaptive/` — слои adaptive-иконок 432×432
